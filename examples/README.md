# Examples

The Web UI's **Sample** button uses a public built-in SVG combining mountains, waves, and a sun. It lets you try every preset without preparing a file.

Image regression testing uses Katsushika Hokusai's *Under the Wave off Kanagawa* with the Woodcut preset and reload-checks a 139 × 83 × 2.0 mm STEP with 48 regions and 230 holes. The expected result is one solid, matching dimensions, zero mesh boundary edges, and zero non-manifold edges. Do not add copyrighted input images to the repository.
