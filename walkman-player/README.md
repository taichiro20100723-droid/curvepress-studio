# MuseWalk

Walkman / Android向けのローカル音楽プレイヤーです。

## 初版の機能

- SDカードを含むMediaStore上の音楽を自動検出
- ジャンル別ブラウズ
- 曲・アーティスト・アルバム検索
- 再生回数
- 完走率
- スキップ率
- 合計再生時間
- 時間帯ごとの再生傾向
- 「今の俺向け」おすすめ
- 最近ハマっている曲
- 久しぶりの曲・未再生曲の発掘
- ミニプレイヤー
- バックグラウンド再生 / メディアセッション
- Android 9以降を対象
- 履歴は端末内だけに保存

## おすすめスコア

再生回数、完走率、スキップ率、現在の時間帯との相性、
しばらく聴いていない補正、未再生曲の発掘補正、
短期間に聴きすぎた曲へのペナルティを組み合わせています。

## デザイン

静かな白黒基調、広めの余白、大きなアートワーク、
常設ミニプレイヤー、ホーム / ライブラリ / 統計の3階層です。
特定製品のUIを複製するのではなく、迷いにくさと情報の優先順位を重視しています。

## ビルド

GitHub Actions の **Build MuseWalk APK** が
`walkman-player/app/build/outputs/apk/debug/app-debug.apk` を生成します。
